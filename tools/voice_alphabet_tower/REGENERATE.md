# Reproduce the alphabet and tower extension

Python 3.12 was used, on CPU with no GPU. The Qwen model needs several GB of RAM;
the full rendering environment had an 8 GiB memory limit. Keep engines in
separate processes. All final runtime assets are already in the owner's full
audio archive; this source-only kit omits model weights and audio binaries.

```sh
python -m venv runtime
runtime/bin/python -m pip install torch==2.6.0+cpu torchaudio==2.6.0+cpu --index-url https://download.pytorch.org/whl/cpu
runtime/bin/python -m pip install -r requirements.txt
runtime/bin/python recovered/Solace-Express-Voice-Regeneration-Kit/download_kokoro.py
runtime/bin/python recovered/Solace-Express-Voice-Regeneration-Kit/download_qwen.py
runtime/bin/python regenerate_additions.py --models recovered/Solace-Express-Voice-Regeneration-Kit/models
runtime/bin/python validate_extension.py regenerated-pack
```

`regenerate_additions.py` replays the final batch seeds, texts, original
directions, generation options, quantization and frozen crop boundaries.
The source pack's original headset filter is unchanged. Use `--engine kokoro`
or `--engine qwen` to render one engine, and repeat `--only LINE_ID` for a subset.
With `--original-pack /path/Solace-Express-Headset-Voice-Pack.zip`, the thirty
reused digit files are copied and hash-checked. Without it their frozen original
Kokoro recipes are replayed, including their original per-line speeds.

`replay-checks.json` compares regenerated bytes with the frozen delivered hashes.
Different hardware or dependencies can change synthesis; inspect and screen any
mismatch rather than substituting a different character preset. The validator
requires the delivered hashes, so a mismatch intentionally fails that check.
Kokoro's ONNX model also contains RandomNormalLike and RandomUniformLike noise
operators, so it can vary on the same hardware. The sample replay matched all
three selected Qwen clips exactly; all ten Kokoro samples retained their exact
frame counts with correlations 0.982–0.997 and different bytes. Use the owner's
finished audio archive for exact assets, and the original-pack option to copy
the thirty existing digit clips exactly.

For new takes and speech screening, install `requirements-qa.txt`, download the
public recognizer with `download_asr.py`, and use the render/crop/screen scripts.
The new-take renderer expects the original reused digits in `work/original/` or
already present in `work/pack/`. The public alignment model URL/hash is recorded
in `work/alignment-model-metadata.json`; it belongs under `work/align-model/`.
`align_qwen_symbols.py` uses raw-carrier verification before CTC alignment. CTC
alignment does not itself validate pronunciation. A carrier with an incorrect
target must be re-recorded, not aligned to a desired transcript and accepted.

No archive decoding from issue comments is needed. All recipes are plain source.
This prepares audio assets; Claude owns game integration and in-game testing.
